# cURL requests
You can use the [Curl-Adapter](https://github.com/Struktal/curl-adapter) libraries `Curl` class to send HTTP GET or POST requests to other servers. The library is a wrapper for PHPs cURL methods.

To learn about how to do that, please refer to the [Curl-Adapter documentation](https://github.com/Struktal/curl-adapter) as it always reflects the latest version of the library.
