# Documentation

## CSV reader
You can use the [PHP-CSVReader](https://github.com/JensOstertag/php-csvreader) librarys ``CSVReader`` class to read CSV files and convert them to arrays.

To learn about how to do that, please refer to the [PHP-CSVReader documentation](https://github.com/JensOstertag/php-csvreader) as it always reflects the latest version of the library.
